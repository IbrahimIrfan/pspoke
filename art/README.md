# Optional PSP menu art

Put your own images here and the next build adds them to the EBOOT (they are not committed to git):

```
art/platinum/ICON0.PNG     144x80   icon in the PSP Game menu
art/platinum/PIC1.PNG      480x272  background shown when the game is selected
art/soulsilver/ICON0.PNG   144x80
art/soulsilver/PIC1.PNG    480x272
```

Use plain (non-interlaced) PNGs, ideally under 300 KB each. Either file can be left out.
